# 戰鬥背景音樂（3 首輪播）部署說明

部署時，請直接將您的三個音檔放入本資料夾（`audio/`，與 `index.html` 同層級），預設檔名如下：

```text
專案根目錄/
├── index.html
└── audio/
    ├── bgm1.mp3   （第 1 場戰鬥開始播放）
    ├── bgm2.mp3   （第 2 場戰鬥開始播放，或 bgm1 播完時自動接續）
    └── bgm3.mp3   （第 3 場戰鬥開始播放，之後再循環回 bgm1）
```

## 若想自訂檔名、副檔名（`.wav` / `.ogg` / `.m4a`）或音量
不需要重新編譯！直接用文字編輯器打開 `index.html`，最上方 `<head>` 內已預留未壓縮設定區塊（`<script id="bgm-config">`）：

```html
<script id="bgm-config">
  window.BATTLE_BGM_TRACKS = [
    'audio/bgm1.mp3',
    'audio/bgm2.mp3',
    'audio/bgm3.mp3',
  ];
  window.BATTLE_BGM_VOLUME = 0.55; // 音量範圍 0.0 ~ 1.0
</script>
```

直接修改路徑或音量後存檔即可生效！

## 輪播與控制機制
- **開始戰鬥時播放**：玩家在對決卡點擊「⚔️ 拔刀開戰！」正式進入 3D 戰鬥畫面時，立即觸發播放。
- **三首輪播（0 → 1 → 2 → 0）**：
  - 每次進入新戰鬥會依序輪播下一首（第 1 戰播第 1 首、第 2 戰播第 2 首、第 3 戰播第 3 首、第 4 戰回到第 1 首）。
  - 若單場戰鬥時間較長、當前音檔播畢（`ended`），也會自動無縫接續下一首！
- **結束或返回時停止**：戰鬥分出勝負或點擊「↩ 重畫」離開戰鬥時自動停止並歸零。
- **靜音連動**：與畫面右上角的「🔊 / 🔇」靜音按鈕完全同步。
- **未放音檔保護**：尚未放入音檔前不會報錯或卡住，原有的打擊／揮劍合成音效照常運作。
